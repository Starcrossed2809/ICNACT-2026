# ICNACT-2026 Website

This is the official website for the **3rd International Conference on Nonlinear Analysis and Computational Techniques (ICNACT-2025)**.

## Conference Details
- **Mode:** Online
- **Dates:** 23-24 July 2026
- **Organized by:** School of Advanced Sciences and Languages (SASL), VIT Bhopal University

## Project Structure
- `index.html`: The main HTML file containing the content and structure.
- `style.css`: The CSS stylesheet for design and layout.
- `script.js`: JavaScript for interactive elements.

## Running Locally
To view the website locally, simply open the `index.html` file in any modern web browser.
